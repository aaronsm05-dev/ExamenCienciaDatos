## Stack tecnológico y librerías

* **Manipulación y análisis de datos (`pandas`, `numpy`, `scipy`):** Carga del dataset *Bank Marketing*, exploración estadística, tratamiento de variables y operaciones matriciales.
* **Preprocesamiento, modelado y validación (`scikit-learn`, `joblib`):** Pipelines sin fuga de datos (`ColumnTransformer`, `OneHotEncoder`, `StandardScaler`), modelos (Regresión Logística, Naive Bayes, SVM y MLP), validación cruzada estratificada y serialización de modelos entrenados.
* **Visualización (`matplotlib`, `seaborn`, `plotly`):** Gráficas del análisis exploratorio (EDA), matrices de confusión, curvas ROC y curvas Precisión-Recall.
* **Interpretabilidad y análisis de errores (`shap`):** Explicación de predicciones e identificación de variables que provocan falsos positivos y falsos negativos.
* **Entorno interactivo y utilidades (`jupyterlab`, `ipykernel`, `python-dotenv`, `openpyxl`):** Ejecución de notebooks exploratorios, gestión de variables de entorno y exportación de tablas de métricas.
